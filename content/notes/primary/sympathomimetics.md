## Receptor profiles

| Drug | α~1~ | β~1~ | β~2~ | Other | Main effect / use |
|---|---|---|---|---|---|
| **Adrenaline** | ++ (high dose) | ++ | ++ | | Anaphylaxis, cardiac arrest, low output; low doses β-predominant; raises lactate and glucose |
| **Noradrenaline** | +++ | + | – | | **Vasodilatory shock** (first-line in sepsis) |
| **Dopamine** | + (high dose) | ++ | | D~1~ | Rarely used now; arrhythmias |
| **Dobutamine** | (+) | +++ | + | | Inotrope; vasodilation may lower BP |
| **Isoprenaline** | – | +++ | +++ | | Bradycardia / heart block (chronotrope) |
| **Phenylephrine** | +++ (direct) | – | – | | Pure vasoconstrictor; reflex bradycardia; obstetric spinal hypotension |
| **Metaraminol** | ++ (direct and indirect) | + | | | Bolus/infusion vasopressor |
| **Ephedrine** | + | + | + | Indirect NA release | Anaesthetic hypotension; **tachyphylaxis**; interactions with MAOIs |

## Catecholamines

- Contain a catechol ring: **not active orally** (COMT and MAO in gut and liver), short half-lives, given by infusion (central line preferred for high concentrations; peripheral infusion of dilute noradrenaline is increasingly used with safeguards).
- Synthesis: tyrosine → DOPA → dopamine → noradrenaline → adrenaline (PNMT, adrenal medulla, cortisol-dependent).

## Direct versus indirect

- **Direct** agents act on receptors; **indirect** agents release noradrenaline from nerve terminals (ephedrine partly, amphetamines, cocaine by blocking reuptake). Indirect agents show **tachyphylaxis** and exaggerated responses with **MAOIs** (hypertensive crisis).

## Non-adrenergic agents

- **Phosphodiesterase III inhibitors** (**milrinone**, enoximone): ↑ cAMP independent of β receptors → **inodilators** (inotropy with vasodilation), useful in β-receptor downregulation; hypotension, arrhythmias; renal excretion.
- **Levosimendan:** calcium sensitiser (troponin C) and K~ATP~ opener.
- **Vasopressin:** V~1~ vasoconstriction; second-line in septic shock (relative vasopressin deficiency); **terlipressin** for varices and hepatorenal syndrome.
- **Methylene blue** (inhibits NO–cGMP) and **angiotensin II** in refractory vasoplegia.
- **Glucagon** for β-blocker overdose; **calcium** for calcium channel blocker overdose and hyperkalaemia.

## Choosing an agent

Think about the cause: **vasodilation** (sepsis, anaesthesia, neuraxial block) → vasoconstrictor; **pump failure** → inotrope (and treat ischaemia, rhythm, loading); **hypovolaemia** → volume first. Match heart rate: bradycardic and hypotensive → ephedrine; tachycardic → phenylephrine or metaraminol.
